# CSE312 - Operating Systems

## Course Description

This folder contains the project for the CSE312 Operating Systems course (Spring 2025). The course introduces how modern operating systems work internally and builds the skills to analyze and design them. It covers processes and threads, scheduling, synchronization, deadlocks, memory management, file systems, I/O, virtualization, and security.

## Course Summary

### Topics Covered

- General introduction to operating systems
- Processes and threads, and process scheduling
- Process synchronization (producer-consumer, dining philosophers, bakery algorithm)
- Deadlocks
- Memory management (address relocation, virtual memory, paging, thrashing)
- File systems and secondary storage management
- Input/Output and disk scheduling
- Virtualization and cloud
- Security

### Textbook

- *Modern Operating Systems*, Andrew S. Tanenbaum and Herbert Bos, 5th edition, Pearson 2023
