# Semester Project: GTU-OS

Objective:
To design and implement a simple multithreaded operating system, GTU-OS, in the assembly language of the hypothetical GTU-C312 CPU, together with a Python simulator for that CPU. The OS keeps a thread table, schedules threads with a cooperative round-robin scheduler, performs context switches, and handles system calls for printing, yielding, and halting.
